# Задача 1.6
Дано: x1, y1 - координати першої точки; x2, y2 - координати другої точки (дійсні числа)

Знайти: d - відстань між точками

Модель: d = √((x2 - x1)^2 + (y2 - y1)^2)

Алгоритм:
   1. Ввести x1
   2. Ввести y1
   3. Ввести x2
   4. Ввести y2
   5. dx = x2 - x1
   6. dy = y2 - y1
   7. d = квадратний корінь з (dx * dx + dy * dy)
   8. Вивести d
   9. Кінець.

Тести: (0, 0, 3, 4) = d = 5

(-1, -1, 2, 3) = d = 5

(1, 1, 1, 1) = d = 0

# Задача 1.9
Дано: a > 0, b > 0, c > 0 - сторони трикутника (дійсні числа).
Обмеження: a + b > c, a + c > b, b + c > a (інакше трикутника не існує)

Знайти: S - площа трикутника

Модель: p = (a + b + c) / 2; S = √(p * (p - a) * (p - b) * (p - c))

Алгоритм:
   1. Ввести a
   2. Ввести b
   3. Ввести c
   4. Якщо a + b <= c або a + c <= b або b + c <= a, то вивести "Трикутника не існує" і перейти до кроку 8
   5. p = (a + b + c) / 2
   6. S = квадратний корінь з (p * (p - a) * (p - b) * (p - c))
   7. Вивести S
   8. Кінець.

Тести: (3, 4, 5) = S = 6

(5, 5, 6) = S = 12

(2, 2, 2) = S ≈ 1.73

(1, 2, 3) = "Трикутника не існує" (крайній: a + b = c)
