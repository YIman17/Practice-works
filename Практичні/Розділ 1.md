# Задача 1.1
Дано:    a > 0, b > 0 — сторони прямокутника (дійсні)

Знайти:  P — периметр, S — площа

Модель:  P = 2*(a + b);  S = a * b

Алгоритм:
  1. Ввести a.
  2. Ввести b.
  3. P = 2 * (a + b)
  4. S = a * b
  5. Вивести P, S.
  6. Кінець.

Тести:   (3, 4) = P=14, S=12;
         (1, 1) = P=4,  S=1;
         (0.5, 100) = P=201, S=50;
