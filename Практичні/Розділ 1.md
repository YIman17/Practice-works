# Задача 1.1
Дано:    a > 0, b > 0 — сторони прямокутника (дійсні)

Знайти:  P — периметр, S — площа

Модель:  P = 2*(a + b);  S = a * b

Алгоритм:
  1. Ввести a.
  2. Ввести b.
  3. P = 2 * (a + b)
  4. S = a * b
  5. Вивести P, S.
  6. Кінець.

Тести:   (3, 4) = P=14, S=12;
         (1, 1) = P=4,  S=1;
         (0.5, 100) = P=201, S=50;
# Задача 1.2
Дано: r > 0 - радіус

Знайти: l - Довжину кола S - Площу круга

Модель: l = 2*πr; S = πr^2

Алгоритм:
  1. Ввести r
  2. l = 2*πr
  3. S = πr^2
  4. Вивести l, S.
  5. Кінець.

Тести:    (1) = l = 6.28, S = 3.14;
          (10) = l = 62.8, S = 314.15;
          (100000) = l = 628318.53, S = 31415926535.89;
